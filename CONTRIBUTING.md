# Contributing / 贡献

Report an issue with a synthetic example, expected behavior and observed result. Do not publish confidential URLs, raw customer data or credentials. Explain changed assumptions and keep English/Chinese instructions consistent. Code changes need a relevant regression test; worksheet changes need a worked counterexample. Contributions must be yours to license under MIT. External sources retain their original terms.

请用合成例子说明问题，不上传客户资料。修改规则时补反例与理由，并同步中英文说明。

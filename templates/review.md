# Link-path review / 内链路径复核

- Inventory sources, export dates, device and rendering mode / 清单来源与采集口径:
- Included page types and exclusions / 分母及排除项:
- Entrypoints and why they represent discovery paths / 起点理由:
- URL variants deliberately kept separate / 保留的 URL 变体:
- Candidate URL and intended user task / 候选页及用户任务:
- Is inventory complete enough to call this an orphan? / 能否确认采集完整:
- Existing incoming sources, relevance and stability / 已有入口及语境:
- Mobile and final DOM checks / 移动端与最终 DOM 核验:
- Minimal proposed repair and exact source paragraph / 最小修复与来源段落:
- Target status and whether it should stay independently discoverable / 目标状态:
- Reviewer, date, rollback condition / 复核人与回退条件:
- Before/after denominator and explanation / 前后分母及变化原因:

A graph signal is a candidate for review, never an instruction to insert links or retire a page.
